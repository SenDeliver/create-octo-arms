# Security Policy

## Supported versions

Only the latest release gets fixes.

## Reporting a problem

If you find a security problem (for example a way to crash or exploit a server through this mod, or to move through walls or fly with forged packets), please **do not open a public issue**.

Report it privately with GitHub's [private vulnerability reporting](https://github.com/SenDeliver/create-octo-arms/security/advisories/new) for this repository. If that is not available, open an issue that only asks for a private contact, without details.

Please include the mod version, the versions of Minecraft, the loader (NeoForge or Forge) and Create, and steps to reproduce. You should get an answer within a few days.
