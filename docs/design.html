Octo Arms — design v1 (+ v1.1 Ships)

A Create addon for NeoForge 1.21.1. A worn Tentacle Rig, built from a Backtank, carries the player on four pneumatic Tentacles over floors, walls and ceilings. Decisions come from the design session on 2026-10-08. v1 is the full feature set; nothing here is deferred.

mod_id: tentaworksdep: Create (Sable optional since v1.1)MC 1.21.1 · NeoForge 21.1.250 · Create 6.0.10

Terms: CONTEXT.md. Decisions: adr/0001 (client-driven movement, cosmetic Tentacles), adr/0002 (Rig = Backtank subclass + own block). Build setup, Create datagen and Ponder patterns: reused from the sibling mod Create Aeronautics: Landing Legs (mod id legworks). Sable is an optional dependency since v1.1 (§10); Aeronautics is not needed.

1. Scope

In v1

  • Copper and Netherite Tentacle Rig, worn in the chest slot, still a working Backtank (diving air, Capacity enchant, back render).
  • Active movement over floors, walls, ceilings, ledges and underwater; Hanging anywhere two Grips exist.
  • Double Jump activation, Setting Down, Crawl on empty Air, Falling when Grips are lost.
  • Rig Settings screen (Standing Height, Speed, Activation Mode), Server Config caps.
  • Enchantable: vanilla chest + Capacity + Far Reach, Thrift, Swift.
  • Tentacle item via Sequenced Assembly, Rig via Mechanical Crafting; Rig Block for refill.
  • Stepping-gait animation visible to everyone, Sticker sounds, goggles tooltips, Ponder scene, JEI via Create's recipe categories.
  • v1.1: grip and ride Sable Ships (also Create Aeronautics Ships), §10.

Not in v1

  • Fighting mobs with Tentacles (v2 idea).
  • Pushing entities, moving blocks, any world force.
  • Other-mod tiers (no extra materials).

  • Active, no input (Idle): held still at the current spot. On activation from a floor the Rig lifts to Standing Height first.
  • Creative: a worn Rig owns the Double Jump. Third jump press while Active, or the fly key, switches to creative flight (Rig Stows).
  • Water: no change. Grips work on underwater faces; diving helmet draws from the same Air.

4. Movement model

The wearer is a point that must stay Held. Held = at least 2 of 4 Tentacles can place a Grip on a solid block face within Reach. Everything else follows from that one rule.

Heading

  • Forward/back = camera look vector (yaw and pitch). Strafe = camera-right, horizontal.
  • Space adds world +Y, Shift adds world −Y. All inputs sum, then normalise to Speed.
  • Blocked component (into a solid face) is removed and the rest slides along the face, so W into a wall climbs it when pitch is up and slides along it when pitch is level.
  • If the next position would not be Held, the move is clamped to the last Held point along the heading. You never fall by walking; you fall only when Grips are destroyed.
  • Player collision box still applies to blocks: you cannot clip through walls, the Rig moves you around them.

Grip selection (server validates, client proposes)

  • Candidate faces: solid block faces (full collision shape, any mod's blocks) within a sphere of radius Reach around the chest. Fluids, entities, non-solid blocks excluded.
  • Each Tentacle keeps its Grip until it is out of Reach, destroyed, or the gait decides to Step. Steps happen one Tentacle at a time, preferring the Tentacle farthest behind the Heading.
  • A Rig is Held if two Grips are valid; the other two Tentacles may be Stepping or hanging free.

Netcode (adr/0001)

sequenceDiagram participant C as Client (wearer) participant S as Server participant O as Other clients C->>C: read input, compute Heading, clamp to Held, setDeltaMovement C->>S: RigMotionPacket(motion, grips[4], mode) S->>S: validate Held (faces exist, within Reach), mirror velocity, reset fallDistance + float counters S->>S: consumeAir(rate by mode), tier/enchant math S-->>C: reject → resync position + state S->>O: RigStatePacket(active, grips[4], step phase) O->>O: animate Tentacles
  • While Active the server applies a transient NeoForgeMod.CREATIVE_FLIGHT attribute modifier (or resets aboveGroundTickCount) so vanilla never kicks for floating. Never the isChangingDimension trick (invulnerability).
  • Fall damage: off while Held; vanilla again in Falling.
  • Elytra and creative flight are suppressed while Active.

9. Art & sound

  • Rig on the back: Create's BacktankArmorLayer draws the tank + cogs; Octo Arms adds a layer renderer for the four Tentacles (segmented piston poles, Sticker tip). Netherite needs its own cog/shaft parts (Create picks copper for non-Create blocks).
  • Stowed: Tentacles folded against the tank. Active: IK-ish two-segment bend from shoulder to Grip, tip pad flush with the face. Step: lift, arc, plant with Sticker's slime sound; piston hiss on height change.
  • Rig Block: backtank model with folded Tentacles.

10. Ships (v1.1, Sable)

Ship blocks are Grips like world blocks, and a Held wearer rides the Ship. Sable is optional ([2.0.5,2.1)); Create Aeronautics Ships are Sable Ships, so they work too. Without Sable, or with ships.grip = false, the Rig behaves exactly as in v1. Plan and steps: plan-v1.1-sable.html.

Frames

  • Ship blocks are real blocks of the same Level at far-away plot coords; the Ship's pose maps them to the world.
  • All Sable calls sit in compat/sable/SableShips behind ShipFrames; NoShips when Sable is absent.
  • A Frame is one Ship at one tick: id, this pose, last pose. Only scale-1 Ships take Grips.

Grips and Held

  • Faces are scanned per Ship in plot coords around pose⁻¹(body), plus the normal world scan.
  • A Grip on a Ship keeps point and block in plot coords; the Ship is found from the block. Packets are byte-identical, registrar 7 → 8.
  • Quadrant test for Ship faces: the face rect is clipped by the body's quadrant planes, then distance to the polygon.
  • Gait scores and distances compare world points.

Riding

  • Carry Ship = the Ship holding most valid Grips (≥ 2). Carry per tick = pose · last⁻¹ · body − body (rotation included).
  • No carry while Sable already tracks the wearer (feet on deck): no double carry. Sable's leftover deck velocity is dropped on activation, on a mid-air catch and every carried tick off the deck.
  • The server checks speed, Air, Crawl and Setting Down on the wearer's own move (move − carry). Air on a Ship uses a 10-tick mean.
  • Server keeps the last 10 poses of every Ship near a player; a client Grip is valid against any of them.

Render

  • Tentacle tips, culling, sounds and particles turn plot points into world points each frame with the Ship's render pose (last → current, lerped), so tips stay on the hull at speed.

Tested and measured

  • Parked and rotated 30°; moving 4 and 15 b/s; yaw 20°/s + roll 10°/s; world ↔ Ship moves; Ship removed mid-grip (wearer falls); standing on deck (no double carry). Sable 2.0.5, Aeronautics 1.3.2.
  • Client vs server lag on localhost: about 1.5 ticks (≈ 0.5 tick Sable pose interpolation + 1 tick player position). 10 server poses leave room for about 400 ms ping (not tested over a real network).
Known limits: other players on fast Ships render ~1.5 ticks behind; a little extra Air when the Ship changes speed; the Rig's own path prediction (clampHeld, gait) does not see Ship hulls, the real move still collides; Ships with scale ≠ 1 are ignored.
