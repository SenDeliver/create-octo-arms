1. Goal

Two Actuators fitted to a Rig. They look cool, feel cool, play cool, help and never annoy. Four Tentacles keep walking exactly as in 1.8.0. The release is 2.0.0 on both Minecraft lines together; this plan builds 1.21.1, the 1.20.1 copy is a later session.

Right Actuator: Far Use

Whatever either hand does, farther. Blocks, mobs and players at the Rig's Reach. Vanilla paths via reach attributes; server checks sight past arm's length. Drops fly home. Rig Setting always / Rig out only / off.

Left Actuator: Grab

Key V, empty main hand, mobs (no boss, no player) and Ships. Held Pinned, low left, out of the crosshair. V again sets down (1 s calm), attack Throws with Impact. Works wherever hands work, Stowed included.

Economy

Rig Air doubled. Actuators sip Air; Deft (one level) makes them free. Speed default = server max.

Look

Rest Pose above the head, wider than the body, idle gestures, telegraph toward grabbables, side entry in first person, opacity slider for all Limbs, Fitting flex, Throw camera kick, Impact clank.

3. Architecture

Movement stays client-driven (ADR 0001). Actuator actions are server-authoritative (ADR 0007 of this branch): the client asks, the server validates and tells everyone. Actuator state lives outside RigServer.Wearer and RigVisuals.Visual because both exist only while the Rig is out.

7. Numbers and formulas

  • Light/heavy: light if w ≤ 1.5 && h ≤ 2.0 && w·w·h ≤ 2.0. Spider 1.76 light, cow light, zombie light, horse 3.1 heavy, enderman heavy (height), golem, ravager, ghast heavy. Ships always heavy.
  • Hold point: camera basis (look, right, up): eye + look·(1.1 + w/2) − right·(0.7 + w/2) − up·(0.55 + h/2 − 0.3), then Hold.place and Hold.sweep. Target stays visible lower-left and off the crosshair ray by at least 0.35 blocks; if the pick ray still hits it, the wearer's pick ignores it (client) and the server skips it as attack/interact target.
  • Far rule: target farther than Reach + 1 for 5 ticks → release "far".
  • Throw: velocity = look × throwSpeed(tier); mob woken before velocity; Impact armed.
  • Impact: at first collision, d = clamp((v − minSpeed) × damagePerSpeed, 0, cap) to the thrown mob and to each living entity whose box it touches (PvP gate for players). Then disarmed.
  • Special Delivery: horizontal distance from throw point to rest point ≥ 20.
  • Heavy: MOVEMENT_SPEED transient × 0.6 on server and client; Rig top speed × 0.6 in RigServer validation and RigClient.
  • Mobs and players: entity range attribute = max(base, Reach); server AttackEntityEvent/EntityInteract past base need sight (WorkSight).
  • Fitting flex: 20 ticks on first wear after the component appears (client-side detection of stack change).
  • Telegraph: client ray hit on a living, grabbable-looking entity (not player, not boss tag) within Reach with empty hand → Left Actuator points, no packet.
