Octo Arms v1.1: Rig grips Sable Ships

Plan, 2026-10-09. Goal: the Tentacle Rig holds, climbs and rides Sable Ships (sub-levels) exactly like world blocks. Sable becomes an optional dependency. Aeronautics not required.
Verdict: feasible with Sable 2.0.5 + sable-companion 1.6.0 alone. Ship blocks are real blocks of the same Level at far-away "plot" coordinates; Sable's chunk mixins make getBlockState/isLoaded work there on both sides. Most work is frame bookkeeping (world ↔ plot). Two hard parts: server anti-cheat vs moving ships, and client/server pose lag.
Backward compat (prod): Grip meaning changes (points may be in plot coords) → bump network registrar 7 → 8. Old 1.0 clients can't join a 1.1 server. No NBT/save change (Grips are in-memory only). Config: new key ships.grip with default = compatible. Ships with scale ≠ 1 unsupported (rejected safely).

2. Design

Frames

  • New Frame: null = world, else ship access + this tick's pose.
  • Grips.Face gets a Frame. Grid scan runs unchanged in plot coords around bodyPlot = pose⁻¹(body) for each ship from getAllIntersecting(bodyBox.inflate(radius)).
  • Rigid transform ⇒ reach/sphere tests unchanged. Skip ships with scale ≠ 1.

Held / quadrants

  • World quadrant planes (X, Z through body) become planes through bodyPlot with normals transformNormalInverse(X|Z).
  • Generalised quadrantDist2: clip 4-corner face rect by 2 half-spaces (Sutherland–Hodgman, ≤6 verts), closest-point distance to polygon. ~40 lines. Keep AABB fast path for world faces.

Grip record: no new field

  • point + block stored in plot coords; ship implied by getContaining(block). Codec/packets byte-identical, meaning changes → registrar "8".
  • Bonus: plot point stays constant on a moving ship, so no relay spam.
  • Add Grip.world(level) resolver for gait score/distance checks (compare world points).

Riding the ship

  • Carry ship = ship holding most valid Grips (≥2), else world.
  • Client onInput: motion = clampHeld(wish) + carry. Skip carry if Sable already tracks that ship (feet on deck) → no double carry.
  • On Rig activate on deck: zero Sable's leftover inherited velocity (internal LivingEntityMovementExtension, isolated).
  • Server: trackRealMove overSpeed, drain() Air, crawl / Setting Down violations must subtract the server-side carry. Otherwise ship riders get stowed + drained.

Pose lag (client builds Grips from interpolated pose)

  • Error ≈ ship speed × latency (20 b/s × 100 ms = 2 blocks ≫ GRIP_SLACK 0.75).
  • Option A (chosen): server keeps ring buffer of last ~10 poses per ship; Grip valid against any, or slack widened by |v|·lagTicks.
  • Option B (fallback after spike): force Sable tracking so Sable syncs pos relative to ship. Internal, fragile (tracking cleared every client move).

Render / FX

  • RigVisuals.Slot tip/normal/from stored as frame+plot point; world via renderPose(pt) each frame.
  • To world also in TentacleLayer.inView, RigSounds, RigParticles, RigServer.resendFalling.
  • RigClient.floorBelow: use level.clip + getContaining so Standing Height works on decks.
  • Known: remote players on fast ships may jitter (packet vs ship snapshot delay).

Collision prediction

clampHeld/firstHeld/gait predictions don't see ship hulls; the real move does. v1.1 accepts this (each tick restarts from real pos). Later: own box test vs ship full blocks.

4. Optional dependency

  • compileOnly sable-companion (+ sable for the 2 internal hooks). All calls in one class compat/sable/SableShips; ModList.isLoaded("sable") ? SableShips : NoShips stub.
  • mods.toml: [[dependencies.tentaworks]] modId="sable" type="optional" versionRange="[2.0.5,2.1)" ordering="AFTER".
  • Build flag -PwithSable adds the Aero runtime bundle (copied from landing-legs build.gradle); default dev run tests no-Sable path.
  • Don't bundle companion jar (Sable 2.0.5 marks companion >1.6.0 incompatible; pinning is fragile).

6. Risks

  • Pose/tick ordering unknown until spike (step 1).
  • Double carry when feet touch deck; leftover inherited velocity.
  • Remote-player jitter on fast ships.
  • Grips spanning world and ship stretch as ship leaves; expect natural Step/fall. Test.
  • Sable internals (2 hooks) may change → pin [2.0.5,2.1).
  • Same-index quadrant from world and ship may be the same real sector (counts as 2). Acceptable.
