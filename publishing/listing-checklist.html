Updating the store pages for 2.0

  1. Merge 2.0 into 1.21.1 first, so the image links in the descriptions resolve.
  2. CurseForge → project → Description: Source/HTML mode, paste publishing/curseforge-description.html.
  3. Update the summary line from the table above.
  4. Images: remove the old gallery, upload the files of the gallery table in that order, hero featured.
  5. Check the relations of the uploaded file: Create required; Sable, Curios, JEI optional.

Modrinth (not listed yet)

  1. Create the project with slug octo-arms, fill the shared metadata, paste publishing/modrinth-description.md.
  2. Upload icon and gallery, submit for review.
  3. After approval: put the base62 project id into modrinth-id in publish.yml, add the secret MODRINTH_TOKEN, add modrinth to the workflow targets, and change the README "Downloads" line.

Releases

.github/workflows/publish.yml runs on a GitHub Release with a tag v<version>+mc<mc>: it builds the jar, attaches it to the release and uploads it to the targets (now github,curseforge). Release notes: publishing/release-notes-<version>+mc<mc>.md, else publishing/release-notes-<version>.md, else python3 tools/release_notes.py <version> <mc> from CHANGELOG.md. The full checklist is docs/RELEASE.md. Only the owner tags and releases.
