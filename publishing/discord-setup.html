Onboarding (so people can pick mod roles)

  • Server Settings, then Onboarding.
  • Default channels: all of them.
  • Pre-join question: "Which mods do you use? You get pings for their releases." Allow multiple answers.
  • Answer "Octo Arms": channel #octo-arms, role Octo Arms.
  • Answer "Landing Legs": channel #landing-legs, role Landing Legs.
  • Finish the Server Guide and Review steps, then enable.

GitHub releases to #announcements

  • Discord: edit #announcements, then Integrations, Webhooks, New Webhook. Copy its URL.
  • In each mod repo: Settings, Webhooks, Add webhook. Payload URL is the Discord URL plus /github. Content type application/json. Events: only Releases.
  • Check Recent Deliveries for a green tick on the ping.
The webhook URL is a secret: anyone with it can post in the server. Never put it in a repo, a commit or a screenshot. Both repos are public.
